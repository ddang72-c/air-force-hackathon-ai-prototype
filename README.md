# AI 기반 감지장비 민감도 조정 및 이상 탐지 프로토타입

공군 해커톤 프로젝트로, 감지장비 오탐 감소를 위해 민감도 자동조정과 이상·노후 장비 탐지를 시도한 Python 기반 AI 프로토타입입니다.

## 프로젝트 소개

기지 방호 환경에서 감지장비의 잦은 오탐은 경계 인력의 반복 출동과 대응 효율 저하로 이어질 수 있습니다.  
이 프로젝트는 이러한 문제를 줄이기 위해, 환경 조건에 따라 감지장비 민감도를 조정하고 이상·노후 장비를 조기에 탐지할 수 있는 방안을 기획한 프로젝트입니다.

프로젝트에서는 풍속, 날씨, 방향, 거리 등의 환경 정보를 바탕으로 적절한 민감도를 예측하기 위해 **Random Forest 기반 접근**을 적용했고, 장비 상태 변화는 **Autoencoder 기반 이상 탐지 방식**으로 접근했습니다.  
또한 결과를 운영자가 확인할 수 있는 UI도 함께 구상했습니다.

실제 하드웨어 데이터 수집에는 한계가 있어, 최종적으로는 **시뮬레이션 데이터 기반으로 Python 프로토타입을 구현하고 실험하는 수준까지 진행**했습니다.

## 문제 배경

- 기지 방호 환경에서 감지장비 오탐이 자주 발생
- 반복적인 출동과 대응으로 인해 운용 효율 저하
- 장비 이상 및 노후화를 사전에 식별할 수 있는 체계 부족
- 환경 변화에 따라 민감도를 수동 조정하는 방식의 한계 존재

## 기술 및 접근 방식

### 1. 민감도 조정
- 환경 변수(풍속, 날씨, 방향, 거리 등)를 기반으로 적절한 민감도를 예측하는 방향으로 설계
- Random Forest 기반 접근 검토 및 프로토타입 구현

### 2. 이상·노후 탐지
- 장비 상태 변화를 이상 탐지 방식으로 접근
- Autoencoder 기반 이상 탐지 방향 검토 및 프로토타입 구현

### 3. 구현 범위
- 실데이터 기반 운영 시스템 구현까지는 진행하지 못함
- 시뮬레이션 데이터 기반 실험 및 코드 수준 검증 수행

## 사용 기술

- Python
- Pandas
- NumPy
- scikit-learn
- TensorFlow / Keras

## 실행 참고

- `models/이상+노후화_탐지_모델_최종.py`는 `np.random.default_rng(123)`으로 **데이터를 직접 생성**하므로 별도 입력 파일이 필요 없습니다. 시드가 고정되어 결과가 재현됩니다.
- `models/민감도_조정_모델_최종.py`는 `data/modeling_data_generated_large.csv`를 입력으로 사용합니다.
- 스크립트 후반부가 참조하는 `score_expanded_operational.csv`는 이 저장소에 포함되어 있지 않습니다. 해당 구간은 그대로 실행되지 않습니다.
- 두 스크립트 모두 Colab에서 작성되어 경로가 상대 경로 또는 Colab 경로 기준입니다. 로컬 실행 시 경로 조정이 필요합니다.
